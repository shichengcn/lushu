## 2. 逐日人流预测与错峰策略

### 2.1 为什么逆时针 = 天然错峰（本次最大的结构性优势）

> Synthesis: 绝大多数国庆青甘团队与自驾车都是"西宁出发先去青海湖、茶卡"的顺时针走法，因为青海湖离西宁最近、第一天就能出片。这造成 10.1–10.3 的车流像一条巨蛇，从西宁头部挤向青海湖—茶卡—德令哈。本次逆时针把这三个点放到 D10（10.4），**在人潮已经西移之后再回头去打卡**，同时把 10.1 这一天放进柴达木无人区。

| 日期 | 顺时针大军在哪 | **本次（逆时针）在哪** | 拥堵判断 |
|---|---|---|---|
| 9.25–9.27（中秋） | 青海湖、塔尔寺周边短途游 | 西宁 → 门源/祁连 → 张掖 | 🟢 门源/祁连非中秋热门，畅通 |
| 9.28（工作日） | — | **张掖七彩丹霞** | 🟢 工作日，全程最舒服的丹霞体验 |
| 9.29（工作日） | — | **敦煌莫高窟 + 鸣沙山** | 🟢 **黄金错峰日**（doc2 明确"莫高窟别卡 10.1"） |
| 9.30（工作日/节前夜） | 部分人已提前出发 | 敦煌 → 当金山 → 大柴旦 | 🟡 节前一天路上开始有车，但戈壁段承载力大 |
| **10.1** | 🔴 **青海湖、茶卡人山人海** | **大柴旦 → 水上雅丹 → U型公路 → 格尔木** | 🟢 **天然错峰**（来源：doc2 第1条） |
| 10.2 | 茶卡 → 德令哈 → 大柴旦（顺向推进） | **格尔木 → 昆仑山口往返** | 🟢 昆仑山口方向车流远小于环线主流 |
| 10.3 | 大柴旦 → 敦煌方向 | 格尔木 → 察尔汗 → 德令哈 | 🟡 与顺向大军开始"迎面交错" |
| **10.4** | 🔴 **顺向大军抵达敦煌** | **德令哈 → 茶卡 → 青海湖 → 西宁** | 🟡 茶卡/青海湖仍有人，但比 10.1 缓解；**敦煌此时最挤而我们已离开** |
| 10.5 | 敦煌/嘉峪关 | 西宁市内 / 塔尔寺 | 🟡 西宁市内景点人多，但可控 |
| 10.6 | 返程高峰启动 | 西宁还车 + 返程 | 🟡 机场/高铁站拥挤，提前 3 小时到 |

**doc3 实走给出的最关键一句情报**：
> "**顺、逆向的两波人在 10 月 4 日前后相聚敦煌，所以感受上敦煌那几天人最多**"（来源：doc3实走）。

本次把敦煌放在 **9.29–9.30**，比"两波人相遇"提前了 4–5 天，**这是整个行程设计里最值钱的一步**。同时 doc3 实走的直接结论是"**国庆逆向完全不堵车，全程顶着限速开**"（来源：doc3实走）——但请配合 05 章：不堵车的路最容易吃罚单。

### 2.3 错峰的三条硬规则

1. **每天 8:00 前出发**（来源：doc2 开篇铁律）。国庆期间热门景区 9:30–11:00 与 15:00–17:00 是两个人流峰；8:00 出发意味着**你在别人到之前已经拍完**。
2. **反着人流的作息**：热门点选**开园即入**或**闭园前 1.5 小时**；无人区点位（翡翠湖、水上雅丹、黑独山）选**中午**——反正光硬也无所谓，人还最少。
3. **不与返程潮抢路**：10.5–10.6 是全国返程高峰，本次这两天只在西宁市内 + 还车，符合规则。

> ✅ 行动项：
> 1. **不要为了"凑整"把敦煌挪到 10.1 之后**——这会让本次行程失去最大优势（来源：doc3实走"10月4日前后敦煌最挤"）。
> 2. 全程执行 **8:00 前发车**，并把每天"最晚 18:00 到店"写进时间线（配合 06 章日落 19:10–19:30）。
> 3. 10.6 返程日按"提前 3 小时到机场/车站 + 提前 1.5 小时还车"预留。
